# SOP — Leave Application and Approval

**Document ID:** SOP-HR-001  
**Document Type:** Standard Operating Procedure  
**Owning Department:** Human Resources  
**Owner:** HR Manager  
**Version:** 2.0  
**Status:** Approved  
**Effective:** 2025-04-01  
**Related Policy:** POL-HR-001  
**Org ID:** ORG-ASTERION-001

## 1. Purpose
Provide ordered steps for employees and managers to request, approve, or reject leave in compliance with POL-HR-001.

## 2. Trigger
Employee needs time off under any leave type defined in POL-HR-001.

## 3. Preconditions
- Employee has active HR system account.
- Sufficient balance exists for the leave type (system-validated) or exception path is used.

## 4. Responsible Roles
| Step | Role |
|------|------|
| Submit request | Employee |
| First approval | Direct Manager (or alternate per POL-HR-001) |
| Acknowledgment / second approval | HR Manager or Department Head when required by duration |
| Balance update | HR system (automated) |

## 5. Ordered Steps
1. Employee opens Leave Request in HR system; selects type, dates, partial-day if applicable, and comments.
2. System checks balance and policy rules; blocks submission if balance insufficient unless exception flag is raised.
3. Request routes to Direct Manager.
4. Manager approves or rejects within **3 business days** (planned leave) with comments.
5. If duration requires second approval (see POL-HR-001 Section 5.4), request routes to Department Head / HR Manager.
6. On final approval, balance is decremented; calendar is updated; employee and Manager receive confirmation.
7. On rejection, employee is notified with reason; no balance change.

## 6. Decision Branches
- **Same-day Casual Leave:** Employee notifies Manager before shift start; enters system request within 24 hours; Manager confirms.
- **Manager unavailable:** Request escalates to Skip-level Manager after 3 business days or immediately if marked urgent.
- **Insufficient balance:** Employee may request unpaid leave; requires Department Head + HR Manager approval.

## 7. Completion Criteria
Approved or rejected status in HR system; employee notification sent; audit log entry created.

## 8. SLA
Manager decision: 3 business days for planned leave. HR acknowledgment when required: 2 business days.

## 9. Exception Handling
CHRO-approved exceptions per POL-HR-001 Section 12; recorded with reason code.
