# Internal Terminology and Abbreviations

**Document ID:** DOC-CORP-004  
**Version:** 1.4 | **Status:** Approved | **Effective:** 2025-01-01 | **Owner:** Data Governance Board  
**Classification:** Internal | **Org ID:** ORG-ASTERION-001

| Term / Abbreviation | Canonical Definition | Domain | Notes |
|---------------------|----------------------|--------|-------|
| ELT | Executive Leadership Team | Governance | CEO + direct reports |
| FY | Financial Year (1 Apr – 31 Mar) | Finance | Always state start year, e.g. FY2025 = 2025-04-01 to 2026-03-31 |
| INR | Indian Rupee | Finance | Primary currency |
| SLA | Service Level Agreement | Operations | Target response/resolution times |
| RAG | Retrieval-Augmented Generation | Technology | Architecture used by Asterion AI Assist |
| CISO | Chief Information Security Officer | Security | Owner of POL-SEC series |
| CHRO | Chief Human Resources Officer | HR | Owner of POL-HR series |
| CDO | Chief Data Officer | Data Governance | Owner of data catalog and classification |
| PO | Purchase Order | Procurement | Formal commitment to vendor |
| WO | Work Order | Operations | Internal maintenance / task ticket |
| CAPA | Corrective and Preventive Action | Quality / Risk | Formal improvement after finding |
| Restricted | Highest internal data classification | Security | Need-to-know + explicit authorization |
| Confidential | Sensitive internal or customer data | Security | Role-based access |
| Internal | Standard company information | Security | Employees only |
| Public | Approved for external release | Security | Marketing, published policies |

**Rule:** When an abbreviation has multiple possible meanings, the domain context and this glossary take precedence. Do not invent expansions.
