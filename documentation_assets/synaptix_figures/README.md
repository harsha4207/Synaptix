## 3. Technical Specifications & Visual Standards

All 27 assets adhere strictly to the following enterprise design requirements:

1. **Resolution & Canvas**:
   - Native resolution of `1600 × 1000` pixels providing crisp rendering when printed or embedded in report documents.
   - Fixed aspect ratio of `16:10` standardized across all architectural schematics and user interface captures.
2. **Typography & Anti-Aliasing**:
   - System Font Hierarchy: `Segoe UI` for display headers, navigation titles, and card headers; `Consolas` for code blocks, payloads, hashes, and data values.
   - Text rendering employs `System.Drawing.Text.TextRenderingHint.ClearTypeGridFit` for maximum subpixel clarity without edge blur.
   - Smoothing mode set to `System.Drawing.Drawing2D.SmoothingMode.AntiAlias` and compositing quality set to `HighQuality`.
3. **Enterprise SaaS Color Palette**:
   - **Primary Brand**: Navy `#0B1F3A`
   - **Accent Blue**: `#1769E0`
   - **Background Fill**: `#F7F9FC`
   - **Card Background**: `#FFFFFF`
   - **Border Outline**: `#E2E8F0`
   - **Muted Text**: `#64748B`
   - **Success Token**: `#16A34A`
   - **Warning Token**: `#D97706`
   - **Danger / Critical Token**: `#DC2626`
4. **Interface Consistency**:
   - Interfaces in Chapter 4 and Chapter 5 feature the consistent 56px sticky application header (`Synaptix Command // v2.0 Enterprise`), workspace domain badge, live latency counter, 220px navigation sidebar with active route indicator, and card padding.
5. **No Dummy Content**:
   - Operational figures reflect real Synaptix Command runtime metrics: live multi-stage reasoning timeline (Intake 18ms -> Router 42ms -> Retrieval 186ms -> Synthesis 166ms = 412ms total), SAP General Ledger variance analysis, 384-dimensional vector embedding statistics, cryptographic SHA-256 approval receipts, and cross-domain zero-leakage isolation tests.
